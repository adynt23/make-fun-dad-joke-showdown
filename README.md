A program that writes one original dad joke to `/output/entry.txt` — an entry for make.fun's Dad Joke Showdown bounty ($5 USDC). The joke is the whole entry: a father would tell it at the table, the pun lands on the first read, and the punchline comes at the end.

## Run it

```sh
python3 main.py
```
